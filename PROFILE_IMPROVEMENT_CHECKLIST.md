## 1. Set Up Profile Summary Cards (REQUIRED for stats to render)

The README references local SVG files at `./profile-summary-card-output/github_dark/`. These are generated by the workflow `.github/workflows/profile-summary-cards.yml` using the `vn7n24fzkq/github-profile-summary-cards` action.

The stats cards will appear broken until this workflow runs successfully at least once.

### Steps

- [ ] Go to [Settings > Secrets and variables > Actions](https://github.com/PauloHSOliveira/PauloHSOliveira/settings/secrets/actions)
- [ ] Create a secret named `SUMMARY_GITHUB_TOKEN`
- [ ] Use a [Personal Access Token (classic)](https://github.com/settings/tokens) with the following scopes:
  - `read:user`
  - `repo` (needed to push generated SVGs back to the repository)
- [ ] Go to the [Actions tab](https://github.com/PauloHSOliveira/PauloHSOliveira/actions)
- [ ] Select the workflow **GitHub Profile Summary Cards**
- [ ] Click **Run workflow** to trigger it manually
- [ ] Wait for the run to complete successfully
- [ ] Confirm the folder `profile-summary-card-output/github_dark/` was generated in the repository
- [ ] Verify that the README at [github.com/PauloHSOliveira](https://github.com/PauloHSOliveira) now renders all stats SVGs correctly

### Expected output files

After the workflow runs, these files should exist:

```
profile-summary-card-output/
  github_dark/
    0-profile-details.svg
    1-repos-per-language.svg
    2-most-commit-language.svg
    3-stats.svg
    4-productive-time.svg
```

### Schedule

The workflow runs automatically every day at 08:00 UTC after initial setup.

## 2. Enable Private Contribution Visibility

This ensures your work on private/company repositories appears in your contribution graph.

- [ ] Go to [GitHub Settings > Public profile](https://github.com/settings/profile)
- [ ] Scroll to **Contributions & Activity**
- [ ] Enable **Include private contributions on my profile**

## 8. Active Workflows

This repository currently has two active workflows:

| Workflow | File | Purpose |
|---|---|---|
| GitHub Profile Summary Cards | `profile-summary-cards.yml` | Generates static SVG stats cards daily |
| Update Profile Stats | `update-profile.yml` | Queries GraphQL API and writes `assets/github-impact.md` |

Both use separate secrets:
- `SUMMARY_GITHUB_TOKEN` — for profile summary cards (needs `repo` scope)
- `PROFILE_STATS_TOKEN` — for the GraphQL stats script (needs `read:user` scope)
